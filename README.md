# One Piece Arc Analysis

Does the anime stretch the story? A data project comparing the pacing of
One Piece's manga and its anime adaptation, arc by arc.

## Status
🚧 In progress

## Data sources
- [One Piece Arcs](https://www.kaggle.com/datasets/tarundalal/one-piece-arcs) by Tarun R Jain (Kaggle), license [CC0: Public Domain](https://creativecommons.org/publicdomain/zero/1.0/). Snapshot from August 2022 (51 arcs, up to episode 1028), stored unchanged in `data-raw/`.

## Project structure
- `data-raw/`: original data, never edited by hand
- `data-processed/`: cleaned data
- `notebooks/`: analysis notebooks
- `src/`: reusable Python code
- `docs/`: decisions and data dictionary
